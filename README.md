# Голосовой помощник (первый этап)

Простое Android-приложение на русском языке.

## Что умеет сейчас

- Кнопка «Говорить» и распознавание русской речи.
- Команда «навигация до <место>» (или «маршрут до <место>») — открывает маршрут в Яндекс Картах, а если их нет, в Google Maps.
- Ответ вслух на русском (если в телефоне установлен русский голос синтеза).

## Как получить APK

1. Откройте вкладку **Actions** в этом репозитории.
2. Выберите последний запуск «Build APK».
3. В разделе **Artifacts** скачайте `voice-assistant-debug`.
4. Распакуйте архив и установите `app-debug.apk` на телефон. Android спросит разрешение на установку из неизвестных источников.
